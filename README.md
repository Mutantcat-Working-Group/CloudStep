### 一、产品概述

- 安全的、高性能的、可独立部署的反向代理与自助负载均衡服务地址管理工具。
- 通过返回集合中设定的地址由开发者再次调用，实现自助负载均衡；也可通过代理直接返回目标地址的请求结果，功能相同或不同、相对路径相同或不同均可代理。
- 支持根路径代理、公网地址或域名代理、失效地址自动屏蔽与失效告警。
- 请求加"盐"机制，实现代理出口变化限制与自嵌套加密。

核心价值：

- 统一多服务器、多服务的请求模式与地址，前端负载均衡与后端代理一站式覆盖。
- 自动排除失效地址，为调用端提供健壮性保障。
- 后端请求地址与功能热更新，无需修改前端代码即可迭代服务。
- 低性能服务器或容器也能通过代理模式提高利用率，支持服务去中心化。

### 二、功能说明

#### 管理界面

- Web 可视化管理映射集、自助模式与代理模式代号。
- 服务器一键 Ping，地址手动或自动生效、失效管理。
- 默认用户名 admin96，可在系统管理中修改密码。

#### 自助模式

- 调用 `/self` 返回可用请求地址，由客户端自行请求，适合代理服务器带宽受限的场景。

#### 代理模式

- 调用 `/agent` 直接返回代理结果，支持根代理与子代理两种模式。
- 失效地址自动停用，10 分钟后复查，连续三次无效则告警并长期停用（可手动解除）。
- 支持 SSL 证书，支持请求加盐。

### 三、安装与下载

从 [Releases](https://github.com/Mutantcat-Working-Group/CloudStep/releases) 下载对应平台的程序压缩包，解压后启动二进制主程序（启动时可在程序名后空格跟随端口号参数）。

1. 准备 gcc 环境或其他 sqlite3 支持环境（一般已自带或被打包进二进制程序）。
2. 解压程序压缩包，启动二进制主程序。
3. 开发者可在代码中自定义后台 token 取值集、token 长度与验密方式。
4. 自编译启动时，请将 static 目录手动复制到 dist 目录（layui 的 node 引入方案尚未完善）。

### 四、快速上手

1. 按指定端口访问地址下的 `/web` 路径进入管理界面，登录后可修改默认密码。
2. 在"映射管理"中添加映射集：上方为映射集设置，下方管理已有映射集。
3. 在"自助模式"和"代理模式"中添加代理路径（way，即坐标）与代理点（point，即映射集），并选择负载均衡模式。
4. 调用程序：
    - 对自助模式路径（`/self`）发送任意形式带参请求，携带 `way` 参数获得可用请求地址。
    - 对代理模式路径（`/agent`）发送任意形式带参请求，携带 `way` 参数获得请求结果。
    - 若开启加盐功能，需按照加盐规则进行请求。

### 五、接口说明

#### 自助模式 `/self`

- 说明：返回可用的请求地址，供调用方手动请求
- 请求方式：任意
- 请求参数（任何形式携带）：
    - `way`：自助模式坐标
- 返回示例：

```json
{
    "code": 0,
    "msg": "success",
    "url": "http://abc.def",
    "way": "abc"
}
```

#### 代理模式 `/agent`

- 说明：根代理模式无法更换路径；子代理模式可在 `/agent/` 后接任意存在的路径，代理请求方式默认与调用请求一致。若调用程序自身带有 `way` 参数与代理坐标参数冲突，原请求参数名改为 `*way**`（对任何请求方式均生效）
- 请求方式：任意
- 请求参数：
    - `way`：代理模式坐标（仅支持路径后 `?way=xx` 传递）
- 返回示例：

```json
{ "返回代理请求结果或返回 body" }
```
